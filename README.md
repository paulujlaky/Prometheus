# Prometheus

A multi-user always-on-agent server built on-top of the Boodlebox semi-public API (`https://box.boodle.ai/api`).

## Setup

```bash
bash pts/server/setup.sh
```

Be sure to set the full, required browser `Cookie` header. Otherwise, nothing will work. Obviously...
